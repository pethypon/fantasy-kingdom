# SBI Trade Assist (自分専用・短期トレード判断支援)

SBI証券の市場を見て「いまどこが良さそうか」を**根拠つきでランキング表示**する、自分専用の
スマホ向けツールです。外部の有料AIには依存せず、**独自の分析エンジン（マルチシグナルAI）**
が複数の根拠を突き合わせて、スコアと**確信度(confidence)**を算出します。

> ⚠️ **重要な前提（必ず読んでください）**
> - これは投資助言ではなく「判断材料の可視化ツール」です。最終判断は自分で行ってください。
> - 短期トレードで「確実に上がる銘柄」を当てることは原理的に不可能です。本ツールは
>   「複数の根拠が一致したときだけ強く推す／一致しないときは正直に様子見と出す」設計です。
> - 個人利用を想定しています。第三者への配布・推奨配信は金融商品取引法（投資助言業）に
>   触れる可能性があるため行わないでください。

## できること

- **モード切替**：短期トレード / ニュース速報重視 / 割安(中長期) / 配当重視 / 様子見強め
- **独自AIスコア**：テクニカル＋出来高＋モメンタム＋ニュース感情を統合した 0–100 スコア
- **確信度**：根拠の「数」と「一致度」から算出。集まるほど・揃うほど高くなる
- **判断理由の可視化**：なぜ買い／様子見なのかを箇条書きで表示
- **4時間ごとの自動更新**：スケジューラが定期的に再分析（クラウド常時稼働を想定）
- **PWA**：スマホのホーム画面に追加して普通のアプリのように使える

## 構成

```
sbi-trade-app/
  backend/                 Python（分析エンジン＋API＋スケジューラ）
    data_sources/          市場データ・ニュース取得
    analysis/              独自AI（テクニカル/感情/統合エンジン）
    storage/               SQLite 保存
    pipeline.py            1回分の分析パイプライン
    main.py                FastAPI（PWAへ結果を配信）
    scheduler.py           4時間ごとに pipeline を実行
  frontend/                PWA（HTML/JS、ビルド不要）
```

## データソースの方針

SBI証券には個人開発者向けの公式APIが無いため、当面は無料データで構築し、
SBI口座の審査が通ったら板情報などを差し替えられる設計にしています。

| 種類 | いま | 将来 |
|---|---|---|
| 株価・出来高 | yfinance（遅延データ） | J-Quants(JPX公式) / 他社API |
| ニュース | 各社RSS（無料） | 有料ニュースAPI追加可 |
| 板情報 | （なし） | SBI口座確定後に検討 |

## 動かし方（ローカル確認）

```bash
cd sbi-trade-app/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1回だけ分析を実行（DBに結果を保存）
python pipeline.py --mode short_trade

# APIサーバ起動（PWAへ配信）
uvicorn main:app --reload --port 8000

# 別ターミナルで PWA を配信
cd ../frontend && python -m http.server 8080
# スマホ/PCのブラウザで http://<PCのIP>:8080 を開く
```

4時間ごとの自動更新は `python scheduler.py` で起動します（クラウドVPS等で常時稼働）。
