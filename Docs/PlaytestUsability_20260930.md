# 操作・表示のテストプレイ改善

Windows版を1920×1080で起動し、新規ゲーム、建築パネルの開閉、メニュー開閉、ユニット選択、移動とAP更新を操作確認。

ゲームルール・ユニット能力・地形や資源のバランスは変更しない。

## 改善
- `Assets/Script/SaveLoad/GameMenuUI.cs`: Escで説明書→メニュー、スロット一覧→メニュー、メニュー→盤面へ戻る。開いているメニューの再構築を防止。InputActionでキー入力を処理し、無効化・破棄時に解除。
- `Assets/Script/UI/GameManualUI.cs`: 閉じた瞬間に描画とクリック判定を無効化し、遅延Destroyまで残らないようにする。
- `Assets/Script/UI/ActionLogUI.cs`: AP枠から離し、色と幅を調整。表示を直近5件に絞り、文章に応じて背景の高さを調整。フォントにない剣・家などの記号を日本語の行動名に変更。不要なRaycasterをなくし、空のログはフェード終了後に更新停止、新規ログで再開。
- `Assets/Script/UI/SlidePanelUI.cs`: アニメーション終点にスナップし、開いた後の微小な位置変更を止める。

## 検証方法
`Tests~/PlayUsabilityTests.cs` を隔離検証環境のSceneSmokeへ組み込む。メニュー階層の戻り、入力イベント、ログのクリック非干渉、休止からの復帰、短いログの背景縮小を確認する。

目視はデスクトップの1920×1080。全解像度・長時間連続対戦を網羅する試験ではない。
