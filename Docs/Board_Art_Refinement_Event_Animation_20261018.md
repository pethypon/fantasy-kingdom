# クリスタルの材質復元・動作限定・造形改善（2026-10-18）

前回の導入後の追加要望を反映した。見た目と演出を変更し、駒の能力・費用・AP・戦闘ルールは変更していない。

## クリスタル

メインクリスタルとサブクリスタルを陣営別の見た目の対象から除外した。元Prefabのモデルとマテリアルを使用する。ロード、表示の再適用、設定変更後の再生成でも、白・黒の陣営材質へ上書きしない。過去の表示が既に関連付いている場合も、元Rendererへ戻す。

サブクリスタルは建物の再焼成・Prefab再保存からも除外した。メインクリスタルのPrefab・依存資産、サブクリスタルのメッシュ・Prefab、既存の陣営材質など、保護対象24点のSHA256が再焼成前後で一致した。実Play Modeでも両陣営の元マテリアル参照を確認した。

`BoardVisualTheme.asset` のSubCrystal項目は既存データとの互換のため残すが、本番の差し替えには使わない。

## 動く条件

駒が動くのは、移動・攻撃・被弾の間だけ。待機の揺れ、呼吸、回転、ゴーストキングの浮遊、汎用スキルの伸縮、独立した撃破演出を停止した。死亡表示のプールも作らない。

攻撃系の固有スキルと反撃は、直接の攻撃ダメージ処理から攻撃モーションへ接続した。回復、補助、供儀、遅延した爆弾・地形ダメージで汎用の動きを起こさない。スキルの効果や対象の被弾処理はそのまま。

動作が終わると、保存した表示位置・向き・スケールへ正確に戻して更新リストから除く。動作中の駒が0体なら、シーン共有DriverのLateUpdate自体を止める。待機中の駒を走査したりSin計算したりしない。

停止中でもQ/EやAIの方向転換は即時反映する。表示用の子だけを動かし、論理位置、当たり判定、占有セル、行動順を補間しない。視界外の動作とセーブ復元時の演出抑制も維持した。

- 通常16職種：胴・腰・首・肩をつないだ石彫の輪郭、腕と装備の接続、馬頭の厚み、兜と胸甲の面取り、尖頭の僧帽を追加。
- 敵17種：小さすぎた武器の縮小率を見直し、厚い剣、中央稜線、裏面と側面のある盾、外套、斥候の眼と旗、忍者の帯などを追加。鯉は縦方向の厚みを増して細さを軽減。
- 強敵4種：翼膜の折れ目と厚み、指骨、外套の襞、大きな盾と剣を改善。
- 建物17種：入口の奥行き、実体のある窓枠、厚い軒、屋根の棟、機能を示す備品を追加。敵側の控え壁を本体へつなぐ。サブクリスタルの形は保持。

材質は従来の既存白・黒・赤を共有し、内容を変更していない。元OBJと軽量化JSONも変更していない。すべて生成済みメッシュを共有する。通常駒は合計20,000三角形、敵・強敵21モデルは54,488三角形、白黒建物36モデルは31,144三角形。通常駒1,800、敵3,400、強敵4,600、建物2,500三角形の各上限を通過した。
