# Fantasy Kingdom ゲーム戦略評価

## 概要

Fantasy Kingdom は Unity 6 製のターン制タクティカルボードゲーム。50x50のPerlinノイズ地形上で、プレイヤー陣営と異形(エネミー)陣営が交互にターンを行い、相手のクリスタル(HP 30,000)またはキング/異形の王を破壊すれば勝利。

---

## 異形の脅威度体系

| 脅威度 | 一般駒 | 指揮官(ボス) | 特徴 |
|--------|--------|-------------|------|
| 1-3 | 動物に異形が寄生したクリーチャー(下級異形) | 人間に異形が寄生した個体 | 単体の生物を取り込んだだけの下級異形 |
| 4-10 | 他の生物と混ぜ合わさった中級異形(中間〜上位) | 無駄を省いた中級異形の上位個体 | 複数の生物を融合した中級異形 |
| 11-20 | 精鋭の中級異形(中間〜上位) | 異形の王 | 中級のコストが下級と僅差に。無駄を省いた精鋭中級 |
| 21-30 | 上位異形(尖った性能 or バランス型) | 異形の王 | 中級とは桁違いの強さ。レベル差を覆せるがコスト重 |
| 31-50 | 二つ名持ちの上位異形 | 異形の王 | 大きなレベル差すら覆す。異形の王に迫る強さ。コスト極重 |
| 51-100 | 二つ名持ちの上位異形 | 異形の覇者 / 魔王 | 強化された異形の王。最終段階 |

---

## 1. 面白さ (Fun Factor): 7/10

### 面白い点

**A. 多層的な意思決定の同時並行**

毎ターン、4つの競合する要求を同時にバランスする必要がある:
- 軍事行動(移動・攻撃・スキル)
- 経済投資(生産施設の建設)
- 領土拡張(サブクリスタル配置)
- 情報戦(霧の戦争、偵察)

共有APプールにより「建物を建てる = 攻撃に使えないAP」というトレードオフが常に発生する。

**B. 非対称なユニットデザイン**

12種のユニットは単なるステータス違いではなく、移動・攻撃の幾何学パターンが根本的に異なる:
- **アサシン**: L字移動(将棋の桂馬的) + 視界外攻撃で1.25倍ダメージ → ステルス戦術
- **マジックスナイパー**: 横4マス射程だが自身のHP20%を消費 → ハイリスク・ハイリターン
- **ガーディアン**: 建物に2倍ダメージ → 攻城特化ユニット
- **アーチャー**: 距離に応じてダメージ+0.25倍(最大+0.75) → ポジショニングが重要
- **ナイト**: 視界内からの攻撃は20%軽減、視界外からは10%増 → 視界管理が鍵

これらのパッシブが相性関係を生む。例: アサシンはナイトに対して極めて有効(視界外攻撃がナイトの弱点を突く)。

**C. 疲労システムによるターン内最適化**

ユニットに行動させるたびに疲労+1 → 次の行動APコスト+1。1体集中運用 vs 分散運用のジレンマが常に存在する。

**D. 生産チェーン経済**

クリスタル収入はゼロ。全資源を建物で生産する必要がある:
```
水(井戸) → 小麦(畑) → パン(パン屋) → 市民 → AP+1/ターン
木(伐採場) → 木板(製材所) → 上位建物
石(採石場) → 石材(石工所) → 上位建物
鉄鉱+石炭(鉱山) → 鉄(精錬所) → 上級ユニット
```

**E. 脅威度による段階的なゲーム体験の変化**

脅威度1-3の下級異形(動物寄生体)との戦いから始まり、脅威度が上がるにつれ中級(生物融合体)→上位(桁違いの強さ)→二つ名持ち→異形の覇者/魔王と、敵の質が劇的に変化する。脅威度21以降の上位異形は「レベル差を覆せる尖った性能」を持つため、プレイヤー側も軍構成の見直しを迫られ、マンネリ化を防ぐ構造になっている。

### 課題点

| 課題 | 詳細 |
|------|------|
| 学習の壁 | 12資源、20+建物、12ユニット、50スキル、35特殊能力、12デバフ、6バフ。チュートリアルなし |
| 序盤の強制感 | クリスタル収入0のため最初3-5ターンは経済建設が必須。戦闘なしの「作業フェーズ」になりがち |
| 広大すぎる霧 | 50x50マップに対し初期領土は半径3(約49マス)。偵察に時間がかかりすぎる |
| キング即死リスク | 経済・位置的優位に関係なく、キング1体の防御ミスでゲーム終了 |
| スキルのランダム性 | ガチャ的にスキル/特殊能力が割り当てられ、同じ戦略判断でも結果が大きく変わる |

## 2. 戦略の奥深さ (Strategic Depth): 8/10

### 5つの戦略レイヤー

| レイヤー | 内容 | 深さ |
|----------|------|------|
| 戦術(ターン内) | 移動パターン、攻撃範囲、方向管理、疲労最適化、スキル選択 | 高い |
| 経済(中期) | 生産チェーン最適化、資源配分、市民成長、AP拡張 | 高い |
| 領土(長期) | サブクリスタル配置(2個/5ターン回復)、防衛ライン構築 | 中程度 |
| 情報戦(継続) | 霧の戦争、偵察 vs 隠密、視界依存パッシブの活用 | 中〜高 |
| 軍構成(戦略) | 12ユニット種の組み合わせ、コスト対効果、相性考慮 | 中程度 |

### 主要な戦略的トレードオフ

1. **ラッシュ vs ブーム**: 早期軍事(召喚+攻撃) vs 経済建設。20AP/ターンでは両立不可
2. **集中 vs 分散**: 疲労で1体集中は非効率だが、集中火力でないと倒せない局面もある
3. **偵察 vs 建設**: スカウト召喚(4AP+資源)で情報を取るか、経済に投資するか
4. **キングの攻守**: 最強ユニット(ATK20, HP800, DEF16)だが即死条件。攻撃的運用か安全運用か
5. **領土タイミング**: サブクリスタルは2個限定。いつ・どこに置くかが長期戦略を決定
6. **対上位異形の軍編成**: 脅威度21+では上位異形がレベル差を覆すため、数で押すか質で対抗するかの選択が発生。コスト重の上位駒を自陣で活用するか、中級精鋭の物量で対処するか

### 他ゲームとの比較

| 側面 | チェス | 将棋 | 囲碁 | Fantasy Kingdom |
|------|--------|------|------|-----------------|
| 情報 | 完全 | 完全 | 完全 | **不完全(霧)** |
| ユニット種 | 6 | 8 | 1 | **12** |
| 経済 | なし | 持ち駒 | なし | **12資源の生産チェーン** |
| 領土 | 暗黙的 | 暗黙的 | 核心 | **明示的(サブクリスタル)** |
| ランダム性 | なし | なし | なし | **中程度(スキル/能力)** |
| 戦略レイヤー数 | 2-3 | 3-4 | 2-3 | **5** |
| 各レイヤーの深さ | 極めて深い | 非常に深い | 極めて深い | 中〜高 |

**総評**: レイヤー数はチェス・将棋・囲碁を上回るが、各レイヤー単体の深さはそれらに及ばない。総合的な戦略的複雑さは「簡略版Civilization + Fire Emblem」に近い。

## 3. 1ターンの打ち手の数 (Branching Factor)

### APコスト体系

| 行動 | 基本コスト | 修正 |
|------|-----------|------|
| 移動 | 3 AP | +疲労 +高低差2 +鈍足/冷気 -迅速体勢 |
| 攻撃 | 2 AP | +疲労 |
| スキル | 2-5 AP | +疲労 -省力化 |
| 建設 | 3-10 AP | 施設による |
| 召喚 | 3-10 AP | ユニット種による |

### フェーズ別分岐数

#### 序盤 (ターン1-3): キングのみ、20AP

| 行動カテゴリ | 選択肢数 |
|-------------|---------|
| キング移動 | 約8 (全隣接マス) |
| 建設(資源が足りる施設) | 約10種 |
| 召喚(資源が足りるユニット) | 約6-8種 |
| ターン終了 | 1 |
| **1意思決定あたり** | **約26** |

20APで平均4APの行動を約5回 → **ターン全体: 約10^5 - 10^6**

#### 中盤 (ターン8-15): 約6ユニット、約6建物、約25AP

| 行動カテゴリ | 選択肢数 |
|-------------|---------|
| ユニット移動 (6体 x 約5マス) | 約30 |
| 通常攻撃 (射程内の敵) | 約5 |
| スキル使用 | 約4 |
| 建設 | 約15-30 |
| 召喚 | 約6 |
| 建物アップグレード | 約3-6 |

| 行動カテゴリ | 選択肢数 |
|-------------|---------|
| ユニット行動 | 約60-80 |
| 建設/召喚/強化 | 約40-70 |
| **1意思決定あたり** | **約100-150** |

### 既知ゲームとの比較

| ゲーム | 1手の分岐数 | 1ターンの分岐数 | ゲーム木複雑性 |
|--------|-----------|---------------|--------------|
| 三目並べ | 約4 | 約4 | 10^5 |
| チェッカー | 約2.8 | 約2.8 | 10^31 |
| **チェス** | **約35** | **約35** | **10^123** |
| **将棋** | **約80** | **約80** | **10^226** |
| **囲碁(19x19)** | **約250** | **約250** | **10^360** |
| **Fantasy Kingdom** | **約30-80** | **約10^6 - 10^8** | **推定 10^150-10^200** |

**重要な違い**: チェス・将棋・囲碁は1ターン=1手。Fantasy Kingdomは1ターン=5-8手の連続意思決定。1意思決定あたりの分岐数(30-80)はチェスから将棋レベルだが、ターン全体では桁違いに大きい。

### AIが示す複雑さの証拠

AIシステムの実装が分岐数の巨大さを裏付ける:
- `SimActionGenerator.GenerateAllActions()`で全合法手を列挙
- 5秒のタイムバジェットで反復深化探索
- トランスポジションテーブル(32,768エントリ)で重複排除
- 最大探索深さ10(最高難度でも)
- QuickScoreによる事前ソートで枝刈り最適化

これらの重い最適化が必要な時点で、探索空間が膨大であることが確認できる。

## 総合評価

| 評価軸 | スコア | 一言 |
|--------|--------|------|
| 面白さ | **7/10** | 多層的設計は優秀だが序盤の緩慢さと複雑さの壁が課題 |
| 戦略の奥深さ | **8/10** | 5つの戦略レイヤーが相互作用。ランダム要素がやや減点 |
| 打ち手の数 | **極めて多い** | 1意思決定: チェスから将棋級、1ターン全体: 10^6-10^8 |

**ゲームの本質**: チェスの位置精度、RTSの経済、ウォーゲームの霧、タクティカルRPGのユニット多様性を融合した「タクティカル4Xチェス変種」。脅威度1-100にわたる異形の段階的進化が長期的なリプレイバリューを提供する。最大の強みはシステム間の相互作用、最大の弱みはアクセシビリティ。
