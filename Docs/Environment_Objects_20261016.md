# 環境オブジェクト

Unityの `Fantasy Kingdom → 開発スタジオ → 環境オブジェクト設定` で設定します。標準データがない場合は画面の「10種類の標準データを作成」を押してください。高さや地表のマテリアルとは別の配置カタログです。

「配置する環境」を選び、8×8のタイルをクリックして配置します。表示する左下座標を変えると、マップの別の場所を編集できます。「消しゴム」で配置を削除できます。各種類の見た目はプレハブを指定します。

| 種類 | 実装したルール | 調整が必要な項目 |
| --- | --- | --- |
| 森 | 奥の視界を遮る、内部の駒の隠密、焼却後は一定期間の煙に変化 | 確認距離、燃焼後の煙の期間・確認距離 |
| 草むら | 内部の駒の隠密。奥の視界を遮るかは独立して設定可能 | 確認距離 |
| 岩場 | 移動と射線を遮る。斜めの角抜けも拒否 | プレハブ |
| 毒沼 | 侵入時と所有ターン開始時のダメージ | 固定値または最大HP割合 |
| 泥 | 移動先の追加AP | 正のAP補正 |
| 道 | 移動先のAP軽減。最終移動APは1以上 | 負のAP補正 |
| 回復泉 | 所有ターン開始時に最大HP割合で回復 | 回復割合 |
| 間欠泉 | 侵入・滞在ダメージ | ダメージ量。最大HP25%は未確定案のため自動設定しません |
| 洞窟 | 指定した離れた出口への移動候補 | 入口ごとの出口座標 |
| 煙 | 奥の視界を遮る、内部の駒の隠密 | 確認距離 |

数値が未確定の項目は未設定のまま保持します。必要な値を設定し、その種類の「ゲームで使用する」とカタログの「このカタログをゲームで使う」を有効にしてから次のマップを生成してください。既存の地形を勝手に置き換えません。

洞窟は片方向の接続です。双方向にする場合は出口側にも洞窟を置いて、入口への接続を設定します。水・高山・岩場・占有マスへは移動できません。敵AI・開発者用プレイヤーAIは、入口と出口の両方を探索済みの場合にだけ接続を利用します。

隠密マスは、自領土内であっても実際の視界で確認する必要があります。森の中から外を見ることはできます。隠密による待ち伏せは既存の視界と駒の能力に接続し、未指定の追加ダメージ倍率は作っていません。第三陣営も森・煙の遮蔽に従います。

燃焼は既存の火炎効果（`FlamePoison`）とドラゴンの炎ブレスが当たったマスに接続しています。今回の16種の固有スキルに未指定の火炎属性は加えていません。別の火炎処理からも `map.Environment.Ignite(position, systems)` を呼び出せます。燃焼後の森、煙の残りラウンド、洞窟の接続、処理済みのターンはセーブに保存されます。

移動とターン開始時にだけ効果を処理し、毎フレームのシーン全検索は行いません。ダメージは共通HP処理を通り、完全無効と実際のHP減少を区別します。AIの危険地形評価は探索済み情報だけを使用します。王の退避判断にも侵入・滞在ダメージを含めます。侵入時は観測済みの防御能力を考慮し、次の所有ターンまでの滞在リスクは保守的な上限として計算して、1回の無効化を2回分に使い回しません。旧シミュレーターに環境効果を無視した結果を上書きさせないよう、環境が観測された局面は既存の静的評価を保持します。

検証コードは `Tests~/TerrainEnvironmentTests.cs` です。森・草むら・煙の遮蔽、岩場の移動・射線、泥・道のAP、毒沼・泉・間欠泉の共通HP処理、洞窟、焼却、煙の経過、保存復元、AIの観測制限を検査します。実行結果は全体の検証レポートを参照してください。
