# AIの領土外探索と移動直後の視界

- `AIBoardState.GetValidMoves` は、プレイヤーと同じ `MapCreate.SetPos` から移動パターン・地形通行条件で候補を作る。未探索の目的地や途中マスだけを理由に除外しない。
- `AIActionExecutor.ExecuteMove` の成功直後に `MarkVisionDirty` と `VisionPoint` を呼び、同フレーム内でも視界を更新する。次の `board.Refresh()` は新たに発見した敵を含める。
- 敵の存在・攻撃対象は引き続き視界で制限する。移動実行時には実際の占有マス・地形・APを再検証し、隠れた駒への重なり移動を防ぐ。
- 建築・召喚可能位置の生成ルールは変更しない。探索済み地形を使う記憶や先読みの情報制限も維持する。

`Tests~/AIExplorationTests.cs` は分離したUnity検証環境で実行する。探索状態を制御した地形上にScoutと隠れた敵を置き、未知マスへの移動候補、領土外移動、同フレームの視界更新、残APによる攻撃候補生成を検証する。隠れた駒による移動拒否とAP非消費、建築・召喚制限も確認する。
