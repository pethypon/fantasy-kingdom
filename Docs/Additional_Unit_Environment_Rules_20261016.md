# 駒・環境・共通ルールの追加 — 2026-10-16

固有アビリティは条件に応じて自動発動し、APを消費しない。能動スキルは「2」キーまたはステータスのボタンから使い、APを消費する。召喚時の能力はランダムにしない。

## 新しい駒

| 駒 | 固有アビリティ | 能動スキル・指定AP |
|---|---|---|
| 白魔導士 | 未設定 | 視界内の味方1体を最大HP30%回復・12AP |
| 聖騎士 | 未設定 | 設定範囲を3ターン、毎ターン最大HP10%回復・15AP |
| 侍 | 通常攻撃で刀ゲージを蓄積。MAX時の被弾後に反撃・吸収 | 未設定 |
| 忍者 | 攻撃しなかったターンごとにクナイ強化、最大5段階。相手の視界外からは通常ダメージ40% | 全マップの味方駒1体と位置交換・13AP |
| 狂戦士 | HPが低いほど通常攻撃APが安くなる | **使うたびに1段階ずつ強化**、最大5段階。必要APは順に5・8・11・15・20 |
| 航海士 | 正面1マスへ通常攻撃。残APによる火力倍率、最大1.5倍 | 視界内の敵を正面へ引き寄せ・12AP |

狂戦士は任意の段階を直接選ばない。最大段階でATK2.5倍、DEF低下と通常攻撃AP+1。通常攻撃1回で、その強化に由来する状態を解除する。他者が付与した通常Buff/Debuffは巻き込まない。

侍は元の攻撃を受けた後、実被ダメージ×0.5＋ATKで反撃し、実際に与えた分を回復する。刀ゲージMAXの保持は最大3ターン。聖騎士は回復中の移動・攻撃ができず、被ダメージが2倍になる。

ゲーム開発スタジオで特殊役割を作る時は、複製元の実際の移動・攻撃・視界マスを独立した設定として保存する。新しいKindに変えただけで通常攻撃が消えることを防ぐ。8×8に収まらない元パターンは切り捨てず、先に個別マスを設定するよう案内する。忍者の正確な遠距離形状など、未指定のマスは作成画面で設定する。

## 既存駒の新アビリティ／スキル

ナイト、アーチャー、魔法使い、アサシン、斥候、プリースト、ガーディアン、クロスボウ、魔法狙撃手、ボンバーの固定能力・AP・操作は[固有能力の実装記録](<E:/fantasykingdom/Unity/fantasy kingdom/Docs/Special_Unit_Abilities_20261015.md>)に記録した。能動効果と常時特性をステータス詳細・召喚説明で分けて表示する。

敵AIと開発者用プレイヤーAIは、共通の合法候補・評価・実行処理から設定済みのスキルを使う。雷杭は2本目までの組み合わせ、回復は実回復量、供儀は味方HPの損失と次ターンの効果を評価する。遅延効果の準備を「即時ダメージなし」という理由だけで失敗学習しない。

## 環境オブジェクト

| 種類 | 実装したルール |
|---|---|
| 森 | 視界遮断・内部の隠密・焼却と煙 |
| 草むら | 設定距離を超えた観測者から隠密 |
| 岩場 | 移動・射線・視界の遮断を個別設定 |
| 毒沼 | 侵入時・自軍ターン開始時のダメージ |
| 泥 | 移動APの追加 |
| 道 | 移動APの軽減。最終移動APは1以上 |
| 回復泉 | 滞在する駒の最大HP割合回復 |
| 間欠泉 | 固定値／最大HP割合による危険地形 |
| 洞窟 | 指定した離れた出口への移動。入口と出口を明示設定 |
| 煙 | 視界遮断・内部の隠密。燃焼後の煙はラウンドで減衰 |

Unityの **Fantasy Kingdom → 開発スタジオ → 環境オブジェクト設定** で設定する。「環境の標準データを作成」で10種類を用意し、見た目・必要値・有効化・配置を指定する。高さ／素材のブロック設定とは別に、8×8の配置画面から各マスへ塗る。洞窟は入口ごとに出口を設定する。

未指定の数値は決めていない。間欠泉の最大HP25%は提案のままにし、有効化する時に割合を設定する。森や草むらの確認距離、毒沼の威力、泥・道のAP、泉の回復量、煙の継続等も設定可能。必要値がない定義は有効にならない。

環境効果は移動時とターン開始時に処理し、毎フレームの全駒検索を追加しない。岩場を通過する移動・配置や、占有済みの洞窟出口への移動を拒否する。AIは探索済みの環境だけで危険・回復・洞窟の価値を判断する。配置・燃焼・煙・処理済みターンはセーブする。

## 共通仕様

- 勢力の最大APは60、個別の能動スキルは最大25AP。通常攻撃と移動はスキルとは別に計算する。
- ユニットはHPを失わない自軍ターン間隔を5回完了すると、その後の自軍ターン開始ごとに最大HPの10%を自然回復する。整数端数は切り捨て、最大HPを超えない。
- HPが1以上減った瞬間、自然回復の待機を0へ戻す。通常攻撃、建物、毒、環境、供儀、爆弾の代償、自己反動、その他のHP書き込みを共通に扱う。回復しても、同じ区間のHP減少は取り消さない。
- 完全無効化で実HP減少が0なら待機を維持する。生命接続では実際にHPを失った駒だけをリセットする。建物は自然回復せず、死亡した駒を復活させない。
- ターン開始の予約ダメージ・毒・環境・クリスタル反撃を処理してから自然回復を判定する。同じターンの重複呼び出しで二重回復しない。
- プレイヤー・敵・第三陣営・強敵で共通処理を使う。待機状態をセーブし、AIの探索クローンと探索キャッシュにも引き継ぐ。旧セーブにない待機実績は作らない。
- HPの内部フィールド変更ではUnityの旧`HP`シリアライズ名を引き継ぐ。通常のセーブ形式のHP項目は変更しない。
