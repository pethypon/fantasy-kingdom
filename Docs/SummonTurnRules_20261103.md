# 召喚上限と召喚直後の攻撃制限（2026-11-03）

陣営ごとの自軍ターンに召喚できる駒を合計2体へ制限しました。兵種や配置元を問わず共通の残枠を使い、次の自軍ターン開始時に2枠へ戻します。

召喚した駒は移動・回復・味方支援ができます。通常攻撃、攻撃スキル、特殊攻撃は次の自軍ターンまで使用できません。敵を対象にする妨害、攻撃準備、雷杭・爆弾なども攻撃系に含めます。侍の自動反撃と反射も準備完了まで抑止し、反撃時のバリア剥離やゲージ消費も発生させません。攻撃制限は相手ターン中にも保持します。

## 実装

- `SummonTurnRules`：陣営ごとに2個のカウンターと攻撃系判定を集約。召喚失敗は枠を戻し、配置不可や資源不足では支払い・生成しません。
- `SummonSystem`：プレイヤーのカーソル配置とAIのKind／UnitData指定を共通経路へ統合。自軍領土・既存の配置／費用ルールを維持。初期配置・ロード復元は召喚数を消費しません。
- `TurnStartHelper`／`Status.ResetTurnFlags`：実際の各陣営ターン開始で、その陣営だけ枠と攻撃制限をリセット。ロードした同じプレイヤーターンは通常の開始処理を再実行しません。
- 戦闘・スキル・ダメージ入口：候補生成だけでなく実行直前にも再検証。通常攻撃、固定スキル、旧式の単体／範囲スキル、特殊攻撃・反撃を対象にしています。自傷・毒・環境ダメージは攻撃禁止によって無効になりません。
- AI先読み：残枠・攻撃準備状態を盤面複製とターン遷移へ反映。置換表のハッシュも両方を区別します。プレイヤーAIの陣営正規化にも対応。
- セーブv13：召喚回数と各駒の攻撃制限を保持。v12以前のデータには履歴がないため、旧駒を攻撃可能・使用枠0として移行。新規召喚から新ルールを適用。
- UI：上限時は召喚不可の理由、召喚直後の攻撃ボタンは「次ターンから攻撃」、攻撃系固定スキルは「次ターンから使用可」を表示。ゲーム内ルール説明にも追記。

Play Modeでは実際の召喚処理、プレイヤー用カーソル配置、敵AI用直接召喚、支払い、3体目拒否、特殊ダメージ拒否、自動反撃・反射抑止、白魔導士の回復、AI実行器による移動、相手／自軍ターン開始、駒の保存復元を実行しました。さらに実シーン全体をJSON保存→復元→PlayerStartから再開し、使用済み枠・攻撃制限とステータスUIが保持されることを確認しました。

テスト用陣営は配置条件・資源・APを明示的に用意した隔離フィクスチャです。移動確認では周囲が実シーンの別駒で塞がれていた場合に空いた試験位置へ配置し直しています。自然な自動対戦やバランス調整の実測結果としては扱いません。途中の試験で発生したフィクスチャの配置・依存注入不備を修正し、上記最終実行で再確認しています。

長時間対戦・全兵種の個別対戦・Playerビルドでの操作は今回未検証です。任意に作成した将来の能力は、攻撃系の判定を追加する必要があります。
