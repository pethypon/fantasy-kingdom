# 領土の一体表示と陣営別マテリアル（2026-09-23）

## 領土
- TerritorySystemはマスごとのPrefab生成をやめ、陣営ごとに1つのTerritoryRegionOverlayを生成。
- 半透明の面と領域の外周のみを描画。隣接マスの共有辺には線を生成しない。
- サブクリスタルの追加・破壊時に同じメッシュを更新。ゲーム上の領土座標・建築・召喚判定は維持。
- 敵領土は現在の視界にある部分だけをメッシュに含める。視界境界を領土境界として描かない。
- 領土にColliderを付けず、選択・移動入力を遮らない。メッシュとマテリアルは終了時に破棄。
- シェーダーをResourcesから参照し、ビルド時にも保持。

## マテリアル
- Image Marbleは地色・薄い筋・濃い筋を分け、日本語Inspectorで色の強さ・抽出範囲・境界ぼかしを調整可能。
- Player Variantに既存プレイヤーの台座・水色のキャラクターマテリアルを割り当て。
- プレイヤー・異形・魔物・強敵の既存の基調色を使った比較Prefab:
  Assets/Prefabs/Units/MaterialPreviews/FactionMaterialPreview.prefab
- ユーザーの訂正に従い、強敵・魔物台座への金属化は取りやめ。両台座の地色・柄色・Metallic・光沢・凹凸を作業前に読み取った値へ戻した。

## 検証
- 領土専用8項目: 共有辺除外、Renderer数、Colliderなし、敵の初期非表示、部分視界、全体視界、縮小、シェーダーコンパイル。
- 既存の独立検証プロジェクトの361項目が通過（SceneSmoke ALL PASSED）。
- 実際のUnityを再生し、初期領土が水色の外周線と薄い面で表示されることを確認。再生停止済み。
- プレイヤー・異形・魔物・強敵の比較PrefabもUnityで確認。

## ラインの意匠更新
境界線をマス別の重なる帯ポリゴンから、各面の外周フラグを使う距離ベースの描画に変更。明るい細縁、内側の細い補助線、淡い色帯を重ね、外向きの角は半径0.14マスで丸める。画面上のピクセル幅に合わせて端を滑らかにする。領域内の面の不透明度を0.055に抑制。
領土メッシュ・視界・コンパイルの8項目を更新して再検証し、すべて通過。Unity再生中のマップを拡大し、境界線と丸い角を確認済み。

## マップ全体のマス境界（2026-09-23）
- MapGridOverlay と Resources/Shaders/MapGrid を追加。BuildTop で地表高に沿う一枚のメッシュを生成し、中立地・水・山を含む全セルの上面に境界を描画。
- 濃い細線と淡い縁、画面微分によるアンチエイリアス。領土の外枠とは別の表示。地形の塗りは変更しない。
- 追加描画は単一 Renderer、Collider なし、毎フレームのメッシュ更新なし。再構築は既存メッシュを再利用。
- Unity Play モードの新規マップを通常倍率と拡大表示で確認。地表のマス線と領土外周を判別でき、未探索の霧を貫通して線が表示されないことを確認。確認後 Play を停止。
