# 開発スタジオの全設定

Unityの **Fantasy Kingdom → 開発スタジオ（日本語）→ 全設定** から開きます。

ゲーム用の設定データを自動収集し、分類・設定名・項目名で探して編集できます。別の設定データベースへコピーせず、ゲームが参照する元のアセットを編集します。今後追加したゲーム用ScriptableObjectも一覧に入ります。

| 変更したいもの | 編集場所 |
| --- | --- |
| 駒のHP・攻撃力・バリア・作成費・維持費・固有能力 | 駒づくり／全設定の「駒・建物」 |
| 移動・攻撃・視界のマス | 駒づくりのタイル編集／行動プロファイル |
| 建物・生産周期・生産量・強化・費用 | 建物づくり／生産調整データ |
| 初期資源・AP・維持費・陣営・地形生成 | 陣営・ゲームルール |
| メインHP・上限・サブHP・欠片報酬・召喚数・通常攻撃回数 | 全設定 → 共通戦闘・召喚・クリスタル |
| AI作戦・経済・住宅・探索・学習・第三陣営 | 全設定の「AI・第三陣営」 |
| 環境オブジェクト・地形の設定データ | 全設定の「地形・マップ」 |
| 登録済みの音・表示テーマ・アイコン等 | 全設定の「見た目・音・UI」 |
| シーン内コンポーネント・マテリアル | Unityで選択 → 全設定の「選択中の部品・マテリアルを編集」 |
| Prefabの構成・部品 | 同じボタンでPrefabを指定して開き、Hierarchyで部品を選択 |
| Unity自体の描画・音・入力設定 | 全設定 → Unityの詳細設定 |

**今回の標準値**：通常攻撃は各駒の自軍ターンに1回。スキル・反撃・反射は別枠です。召喚は各陣営の自軍ターンに合計1体。メインクリスタルは初期1000／上限2000、サブクリスタルは500です。標準サブクリスタルのHPは共通設定を優先し、独自建物は専用のHPを使います。

変更後は「変更を保存」または「すべて保存」を押します。Undoにも対応します。Prefab内の部品はPrefab編集モードで変更してください。部品の保存はそのシーン／Prefabの保存になります。

再生中は閲覧のみです。共通ルール・初期資源・地形・見た目の配置は、停止中に保存し、**新規ゲーム**で確認してください。試合途中の動的なルール切替は保証しません。既存セーブのメインクリスタルは新しい上限へ移行し、HP割合と死亡状態を保ちます。召喚上限を下げても、保存済みの召喚回数から追加の枠が生まれることはありません。

一覧には未登録・旧版・試作データも含まれます。編集しただけで未登録の駒・建物・スキルが出現するわけではありません。専用タブで登録するか、使用中のカタログ／設定から参照させてください。保存用の駒・建物IDは全設定でも変更不可です。

対象は**既存のシリアライズされた設定データ**です。新しい能力処理・ゲームシステム・AIアルゴリズムの作成、まだ設定化されていないコード内定数までを自動編集する機能ではありません。一部の詳細項目は元の英語名を表示します。非公開の一時状態やセーブ互換用の非表示フィールドは編集対象にしません。
