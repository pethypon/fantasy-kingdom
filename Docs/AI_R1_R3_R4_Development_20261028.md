## 4. R1の追加開発

- `AIOperationSquadConfig`：生成した一時ScriptableObjectだけを所有・解放。既存アセットを破棄しない。数値範囲とNaNを検証。
- `AIIntegratedConfigMenu`：日本語メニューから、所定のResources内の部隊設定・思考時間設定を作成／選択。既存設定を上書きせず、SceneやPrefabを保存しない。
- `AIOperationManager.SquadLifecycle` / `.Squads`：死亡・陣営変更・建物・重複所属・古い所属索引を除外。無効な駒で補充枠を埋めない。ロード後は古い隊列位置・中継点を再計算。
- `AICommander.ThinkingBudget` / `EnemyMove` / `DeveloperPlayerAIController` / `AITurnBudget`：現在の思考処理の識別番号で予算を受け渡す。初期化も正式残時間で制限。開発者AIの監視時間は実時間で測り、メニュー中は停止。
- `AIStrategicGovernor.OperationRecruitment`：複数部隊から同じ役割の補充要求が来た場合、需要を合計してから既存の購入予定を一度だけ差し引く。1回最大3購入、正式な支払い、市民の自然増加を維持する。
- R1の晶・思考時間の既存テストソースを`Tests~`から登録可能なEditor条件付きテストへ移し、共通入口へ接続。自動実行はしない。

既存の探索実績、個体保全、長期軍備需要、住宅・自然市民増加・有償召喚の連携を維持する。
追加した内容：

- `AIStrategicGovernor.Development`：同兵種の先行行が準備期間外・必要数ゼロ・充足済みでも、後ろにある有効な需要を隠さない。
- 新しい保存契約ソースを共通RunAllへ登録。軍備の重複行については既存の隔離fixtureにもケースを追加したが、どちらも未実行。

## 9. 設定・戻し方

Unityの「Fantasy Kingdom / AI」から次を開く。

- **R1 部隊編成の設定**：部隊人数、連携距離、集合待ち、連携の上限。
- **R1 戦況別の思考時間**：既存の通常2〜3秒・交戦4〜6秒・連携5〜7秒・重大6〜8秒の範囲。正式時計が短ければそちらを優先。
- **R4 自律戦略の設定**：`Resources/AI/CognitiveAIConfig`。既定はEnabled=false、ShadowMode=true、行動への反映=false。

記録だけを得る段階ではR4を有効にしてShadowModeを維持する。行動反映・複数手順・一般化経験は別々のフラグであり、正式受入前に一括で本番ONとはしない。
R4を戻す場合はEnabled=false。既存の作戦・経済・晶ルールを残して通常AIを使用する。
