# 駒固有能力・操作・設定 — 2026-10-15

今回の仕様を駒の固有スキル・固有アビリティとして実装した。召喚時のランダム配布と3択による置換は行わない。旧スキルの効果表は互換性のため保持するが、固有能力がある駒へ旧割当を重ねない。旧セーブのランダム割当も、現在の駒定義の固定能力を優先する。進行中の儀式・爆弾・杭・生命接続などの特殊状態は保持する。

最終更新：2026-10-16。以下の設定・操作は敵AIと開発者用プレイヤーAIで共通。

## 操作

- 自軍ターンに駒を選び、キーボードの **2／テンキー2** またはステータス欄の固有能力ボタンを押す。未設定の能力は理由を表示する。文字入力中・敵ターン・開発者AI自動操作中は発動しない。
- 魔法使いは対象を選び、供儀する味方を複数選択する。全合法対象を選べる。AIの代表候補への枝刈りをプレイヤーの操作制限にはしない。
- ステータス欄の **能力・スキル詳細** で効果・代償・対象・残りターン・現在倍率を確認する。
- 召喚一覧の駒へカーソルを合わせると、制作費、Lv1維持費、HP・攻撃・防御、固有スキル、固有アビリティを表示する。スクロール・一覧を閉じる・行の無効化で表示を消す。
- マジックスナイパーはロックの発射可能ターン以降、同じ固有能力画面の **ロック対象へ射撃** で通常攻撃する。合法ロックに限り距離・視界制限を外す。
- 視認できる駒が固有スキルを発動した時は、行動ログに駒と能力名を表示する。霧の奥で見えない敵の発動名は表示しない。

## Unityでの設定

ゲーム開発スタジオの「駒」から対象を選び、**駒固有能力** の設定を開く。能力定義は駒データの `specialSkill` で参照する。通常スキルの倍率欄で複数ターン能力を代用しない。

**Fantasy Kingdom → 駒固有能力 → 既存の駒へ設定雛形を追加** は、未割当の駒へ独立した設定ファイルを作る。既存の設定は上書きしない。雛形のAPは指定表を適用し、未確定項目を入力してから「ゲームで有効にする」を選ぶ。新6種はスタジオの特殊ユニット作成から、選択中の駒を元に独立コピーできる。基礎ステータス・制作費・行動マスはその駒のデータで調整する。

**未確定値は決めていない。** クールダウン、ナイトのATK低下率、アーチャー中間曲線、供儀人数上限、雷線の陣営判定、狙撃の反動曲線、爆発範囲・陣営・死亡時、聖騎士の範囲・中断、刀ゲージ、忍者のクナイ曲線、狂戦士の段階・通常攻撃AP曲線、航海士のAP曲線は編集可能。必要項目が不足する能力は発動を拒否する。忍者の位置交換は全マップの味方駒が対象。新6種の行動マスは複製元の実際の設定を独立保存し、未指定の射程等は8×8マス設定で決める。航海士の通常攻撃は正面1マス。

## 実装と互換性

- `SpecialSkillDefinition` をゲーム本体・AI・UIが共有。`SpecialState` は通常Buff/Debuffと分離し、安定した生存IDを保存する。古いKindの数値は変更せず6種を末尾へ追加した。
- HP変化は通常ダメージ・DEF無視・直接HP削減・強制死亡を区別。直接の代償は無効化・転送・被害倍率を通さない。生命接続は一度だけ転送し、致死交換時に解除する。実受領者に経験値・被害統計を帰属させる。
- 雷線は同じ移動で同じ線から一度だけ被弾する。杭の更新で経過ターンを戻さない。爆弾は術者死亡後も付与時の爆発設定を保持する。
- 自軍ターンの予約処理はラウンドごとに一度だけ進む。ロック対象がロード時にいなければ該当状態だけ解除する。
- AIは既存の合法候補・評価・実行へ統合。供儀は最大4代表、対象数も上限を設ける。未来価値、味方HPコスト、本人の危険、雷線、儀式中断、無効剥がし、固定砲台の保持等を評価する。未表現の遅延状態を旧Minimaxへ誤変換せず、専用の将来評価を保持する。
- AIの特殊能力の観測と学習は現在見える相手だけ。合法ロック以外で見えない現在位置を引かない。学習は件数上限付き平均値だけを保存し、ルールを書き換えない。
- 生成・ロード・開発スタジオのプレイ中更新で同じ固定能力の適用処理を使う。設定更新で旧ランダム能力が戻る経路を修正した。無効な狂戦士のAP／防御補正、侍のゲージ加算・反撃も働かない。

## AIのスキル使用

通常の候補生成・評価・作戦上の優先順位・行動選択・実行へ固有スキルを接続した。敵陣営と開発者用プレイヤーAIの両方が、プレイヤーと同じ合法対象・AP・待機ターンを使う。常時能力はボタン操作なしで共有ルールが適用する。

回復は実際に回復できる量と救命効果を評価し、満タンや1HPだけの回復へAP12を浪費しない。雷杭は最大8体の可視候補から2本目を置ける組み合わせを調べ、両方のAP、待機、杭の寿命、味方への巻き込みを評価する。1本目だけの低い価値で準備を永久に拒否する問題を修正した。将来の滞在は不確実として割り引き、見えない端点の現在位置は参照しない。同じ候補評価内のダメージ計算を再利用し、候補評価後に参照を解放する。

自己評価も固有状態の実変化を検知する。儀式・杭・接続などの準備を、即時ダメージがないだけで失敗と扱わない。固定能力の種類ごとに学習キーを分け、実際に何も変化しない実行成功には準備の実績を与えない。

実装上の解釈：狙撃ロックは次の自軍ターンから最初の通常射撃まで保持し、射撃後に解除する。聖騎士は発動後3回回復し、最終回復ターンまで行動不可・被ダメージ2倍を維持する。既存Kind由来の常時補正の数値は変更していない。狙撃の既存通常攻撃時の反動と、新しいロック中の毎ターン反動は別経路で残る。
