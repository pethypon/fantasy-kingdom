# 霧・操作・UIの調整箇所（2026-09-28）

## 霧

- `Assets/Script/Mapsystem/FogChunkRenderer.cs`：16×16チャンクごとに未探索・探索済みの2メッシュ。同じ高さの面を結合し、同じ状態の内部壁は生成しない。視界が変わったチャンクだけ更新する。
- `Assets/Shaders/CartographicMist.shader`：上面・側面で投影面を切り替え、どの方向からも雲模様を表示する。テクスチャ参照はピクセルあたり2回。地形との同一面によるちらつきを深度バイアスで防ぐ。
- 下面は地形下面から0.02離す。`MapCreate`ではワールド座標の地形に合わせて霧を作るため、生成オブジェクトが原点以外でもずれない。
- 色・雲の大きさ・速度は `Assets/Resources/Terrain/UnknownMist.mat` と `ExploredMist.mat`。未探索は不透明・深度書き込み、探索済みは半透明。

35×35マップの分離検証：

|項目|変更前|変更後|
|---|---:|---:|
|描画オブジェクト数|54|18|
|全域が未探索の頂点数|207,025|120|
|探索済み領域と可視領域がある場合の頂点数|198,744|312|
|視界を変えながら200回更新|435.797ms|36.563ms|

更新時間はこの検証ケースで約92%減。ゲーム全体のFPS改善率ではない。地形やユニット数、GPUによって実際の負荷は変わる。

## 操作

- 中ボタン（ホイール）を押してドラッグ：マップ上をつかむようにカメラを移動。`TurnCameraController.cs`。
- UI上でホイールを回す場合はカメラのズームを抑制。`TurnInputHandler.cs`。
- 敵ターンにユニットをクリック：ステータス、青い移動候補、赤い通常攻撃範囲を確認。右クリックで閉じる。
- 確認中の範囲は現在位置・地形・占有状態に基づく。APを消費せず、移動・攻撃・建築の命令は送らない。視界外の敵は選択できない。
- `TurnInspectionController.cs`は専用の再利用メッシュで表示し、AIや通常操作の範囲バッファを変更しない。範囲は選択中のみ0.15秒間隔で更新。
- `EnemyMove.cs`と`AICommander.ExecuteTurnSteps()`でAIの行動間にフレームを返し、カメラや選択の入力を処理する。思考予算はフレーム待ち時間を除いたCPU処理時間で計測する。

## UI

- `Assets/Script/UI/UIBuilder.cs`：ターン・タイマー・全体の配置。タイマーは装飾枠と細い残り時間バー。
- `UnitPanelUI.cs`：建物の右コマンド欄を攻撃/取消、強化/費用、破壊の3段に分ける。
- `UnitHeadUI.cs`：HP/Lvを共通の`UnitHeads`階層に置く。選択中の駒を他のHP表示より前に描画し、通常のHUDより下に置く。駒ごとのCanvasは追加しない。
- `UIFactory.cs`と`BuildSummonUIBuilder.cs`：スクロールバー幅28、表示を固定、スクロール感度42。
- 装飾の差し替え：`Assets/Resources/UI/SteampunkUITheme.asset`。

## 新しいクリスタル

ユーザー作成のプレイヤー・敵クリスタルVariantを使用する。モデルとマテリアルを維持し、陣営、Crystal種別、HP15,000、クリック用の判定を設定する。

`CrystalSystem.ConfigureCrystal()`は新規ゲーム・ロード時の両方で実行。台座だけに当たり判定があっても、上部の結晶をクリックできるようモデル全体を覆うBoxColliderを補う。

プレハブ自体を整えるメニュー：`Fantasy Kingdom > Terrain > クリスタルの陣営と判定を整える`。
