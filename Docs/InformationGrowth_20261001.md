# AI情報戦・Lv100・固定成長（2026-10-01）

依頼資料「Fantasy_Kingdom_AI_Lv100_成長_改善点 (1).md」の3項目を実装。建築・召喚のルールは変更しない。

## 調整場所
- `Assets/Script/Common/GameConstants.cs`: `MaxUnitLevel = 100`。
- `Assets/Script/Unit&Battle/UnitData.cs`: `CalcGrowthPerLevel` と `CalcStat`。InspectorのLv1基礎値・成長率から、四捨五入した最低+2の固定増加量を計算する。
- `Assets/Script/Unit&Battle/Status.cs`: XP・レベルアップ・撃破後リセット。XP閾値は100段階の配列で一度計算し、以後の取得は定数時間。経験値・ステータス加算はint上限で飽和。
- `Assets/Script/Gamesystem/TurnSystem/Enemy/AIReconnaissance.cs`: 情報価値、探索方向の分担、記憶に基づく推定、危険・重複評価。
- `Assets/Script/Gamesystem/TurnSystem/Enemy/AICommander.Recon.cs`: 戦略に依存せず、安全で有益な斥候移動を最大1回先行。APの3分の1以内、低HP・大きな予想被害・直ちに敵を倒せる状況は除外。
- `Assets/Script/Gamesystem/TurnSystem/Enemy/AIBoardState.Recon.cs`: 観測済み情報への入口。通常指揮・師団長指揮の双方で共通評価を使用。

## AI情報戦
- 脅威度1〜10: 未探索領域への単純な視界獲得。
- 11〜20: 斥候を優先し、全戦略で安全な先行偵察を行う。
- 21〜30: 最大8方向の未探索セクターを分担。視認した敵の種類・向き・最後の位置から周辺を再捜索する。
- 31〜50: 視認中の移動履歴による進行方向の重み付け、遠距離駒の射程内を見通す価値、敵斥候の排除を評価する。
- 51〜100: 移動形状を複数段階展開して候補位置を推測し、クリスタル周辺の未監視領域にも価値を付ける。

敵の実位置・HP・種類をFog越しに照会して探索先を採点しない。敵・建物・クリスタルの重要度は観測記憶から与える。未発見のものについては未探索セルの情報獲得期待値を使い、何が隠れているかを先読みしない。

候補位置は予測であって確定情報ではない。既に見えていて空のセルを除外し、記憶は7ターンで失効。地形の推定判定も観測済みセルだけを利用する。実際の攻撃可否と移動後の視界は既存の正式な判定を使う。

計算量を抑えるため、推定位置は接触ごとに最大256セル・3段階に制限。1ターンに複数行動できるため、推定範囲は厳密な到達可能範囲ではない。視界予測も基本視界を使った見積もりで、高台・能力補正を含む実視界は移動後に再計算する。

盤面更新単位でスコア・セクター・推定領域をキャッシュし、記憶の位置リストも再利用。古い観測は除去する。8方向が埋まった場合、追加の斥候は専用セクターを持たず、重複ペナルティと情報価値によって移動先を選ぶ。

## 固定成長
`増加量 = max(2, floor(Lv1基礎値 × 成長率 + 0.5))`

`LvN値 = Lv1基礎値 + 増加量 × (N - 1)`

カスタムUnitDataも同じ式を使用。撃破後のリセットもそのUnitDataの基礎値を維持する。死亡した駒はレベルアップしても復活しない。HPの欠損量と追加獲得ステータスは維持する。

旧セーブの保存済みHP/ATK/DEFは破壊的に再計算しない。以後のレベルアップで新しい固定増加量を加算するため、旧ルールで既に成長した駒の値は新規生成した同レベルの駒と異なり得る。新規ゲーム・新規生成では上記式に一致する。

UIのMAX表示はLv100、頭上Lvメダルは3桁の自動縮小に対応。説明書は百分率表示から固定増加量の表示に変更。
