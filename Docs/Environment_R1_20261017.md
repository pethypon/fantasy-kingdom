# 環境地形 R1 統合差分（2026-10-17）

既存の `TerrainEnvironmentRuntime` / `TerrainEnvironmentDefinition` を拡張しています。地形を別管理する並行システムは追加していません。

- 森内部の視界を1マス減らし、最低1マスの近距離から発見可能にしました。森の中から攻撃した駒は設定された期間だけ露見します。位置ではなく生存個体IDを保持し、移動先へ追従して期限切れで破棄します。
- 岩場の被遠距離ダメージ倍率0.75とStoneタグのダメージ倍率1.25を共通照会として提供します。文字列による攻撃名の判定は使いません。
- 間欠泉は未発見の隠し地形で、侵入時に最大HPの25%を共通HP経路で処理します。強制移動も同じ侵入処理を通ります。発見履歴は陣営ごとに保存し、探索済み地表から隠し地形の正体を推測できないよう既知地形APIへ接続しています。
- 焼却した森は設定された期間だけ煙へ変化します。標準値は30ラウンド・毎所有ターン最大HP10%。直接配置した煙にも同じ持続・ダメージ規則を使います。
- 洞窟は相互接続された2地点で1組です。使用AP3、開始時は転送を予約し、次の所有ターン開始時に共通強制移動経路で到着します。1組につき同時利用1体。到着ターンは再利用できず、その後の待機ターン数は設定値に従います。出口が占有された場合は安全に保留して次の所有ターンで再確認します。
- 発見陣営、煙、攻撃後露見、洞窟利用者・開始ターン・目的地・再利用制限を既存セーブへ追加しました。未発見地形の情報は評価用APIで公開しません。
- 環境設定画面の日本語項目、相互接続ボタン、未確定値の説明を更新しました。カタログの有効化や実配置は自動では変更していません。

## UNRESOLVED_BALANCE

森の発見距離・攻撃後露見期間、草むらの発見距離、毒沼の侵入/滞在ダメージ、泥/道の移動AP補正、回復泉の回復量、洞窟の再利用待ち期間はユーザー設定値です。未設定では該当地形を有効化しません。煙の見通し距離も既存の設定欄で指定します。

## 互換性と検証

仕様書にある `VoxelMap3D` / `DDA` / `Reachable3D` は現在のチェックアウトにはありません。既存の地表マップと `HasClearTerrainLine` を維持し、洞窟到着には実際の地表Yを使います。立体ボクセル用の別系統は新設していません。

`Tests~/TerrainEnvironmentTests.cs` に陣営別発見・AI透視防止、森の露見/追従/期限、岩場の倍率、洞窟のAP/次ターン/単独利用/保存/再利用制限、煙ダメージ等の回帰を追加しました。実行結果は親タスクのUnity検証ログを参照してください。
