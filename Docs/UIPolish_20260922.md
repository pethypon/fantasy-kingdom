# UI追加改良（2026-09-22）

- ステータス欄の上に所属・対象種別・操作モードを表示する見出しを追加。
- ユニットのレベル欄に、次のレベルまでの必要XPを表示。Lv10はMAXと表示。施設には経験値を表示しない。
- ATK/DEFを「攻撃力」「防御力」に変更。スキルモードもボタンに表示する。
- 上部にターン終了ボタンを追加。プレイヤーの移動・攻撃モードのみ有効。攻撃モード中も終了処理とマーカー解除を実行する。
- 建築・召喚一覧の見出しを区別。
- スタン中のスキルボタンを無効化し、攻撃ボタンと統一。

Unity 6000.3.8f1の実プロジェクトを1280×800で再生。駒選択、見出し切替、攻撃モードからターン終了でTurn 2への進行、建築/召喚一覧をマウスで確認。
隔離プロジェクトの回帰テスト361項目成功（Core54、Optimization37、Scene43、Visual216、StatusUI11）。
Windows64非Developmentビルド成功（errors=0、warnings=0）。確認後はUnityの再生を停止。
