# 陣営別の造形・既存マテリアル・アニメーション（2026-10-18）

この文書は初回導入の記録。現在の仕様は `Docs/Board_Art_Refinement_Event_Animation_20261018.md` を参照。追加要望によりクリスタルを陣営表示から除外し、待機・汎用スキル・撃破の動作を停止している。

今回の優先依頼を本体プロジェクトへ反映した。敵の異形モデルは、指定された鯉・羊・蟹・犬のOBJ本体を使用する。味方は通常のファンタジーの駒、環境は通常の自然・危険地形とし、敵だけの異形化を区別した。

## 反映した見た目

- 敵17種：王と16職種。4つの本体に武器・杖・盾・冠・爆嚢などを組み合わせ、役割を区別。
- 強敵4種：ゴーストキング、ドラゴン、反逆の騎士王、雷の魔導兵。別のメッシュと輪郭を持つ。デコイと親衛騎士にも赤の表示を適用。
- 通常16職種：既存の通常チェスモデルを白大理石へ統一。初期の完成済み味方モデルは元の造形を保持。
- 建物18種：通常形と、棘状の控え柱・封印などを追加した敵形。合計36メッシュ。
- 環境10種：森・草むら・岩・毒沼・泥・道・回復泉・間欠泉・洞窟・煙。根、倒木、シダ、岩の層、水際などを追加。森・草むらの3〜4セル生成ルールは前回実装を維持。

## アニメーションと軽量化

骨のないモデル向けに、待機、短い移動、通常攻撃、スキル、被弾、撃破の動きを追加した。駒全体の踏み込み・傾き・揺れ・伸縮であり、骨格付き歩行クリップではない。砲撃建物の攻撃にも接続した。

ゲームのルートTransformとColliderを動かさず、表示専用の子だけを動かす。HP・AP・占有位置・行動順・セーブ値を補間しない。セーブ復元中は戦闘演出を抑制し、Fog外の敵や攻撃対象を演出で漏らさない。

更新はシーン共有のDriver1つ。駒ごとのAnimator・Update・Coroutine・動的材質・リアルタイムLight・ParticleSystemは追加しない。画面外では待機計算を省き、建物は演出中だけ更新する。退場表示は最大8個を再利用し、0.3秒で参照を解放する。

元OBJ本体は鯉2,072／羊1,799／蟹1,798／犬1,799三角形へ削減。元OBJ4ファイルのSHA256が一致し、原本が変更されていないことを確認した。完成21モデルは合計53,182三角形で、各1Mesh・1Renderer。環境も各900三角形以下、1Mesh・1Renderer。実行時のOBJ/JSON解析やメッシュ生成はない。

## Unityでの調整場所

`Assets/Resources/GameContent/BoardVisualTheme.asset` を選択する。Inspectorは日本語で、駒・建物・強敵のモデル参照と共有材質を変更できる。既存の独自モデル・独自定義は許可リストに含めない限り差し替えない。

Unityメニュー：`Fantasy Kingdom → 開発スタジオ → 見た目`。生成済みモデルや意図的な無効化を、再導入で自動上書きしない。
