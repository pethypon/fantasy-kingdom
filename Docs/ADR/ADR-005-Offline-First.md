# ADR-005: 本編とAIをローカルで運用する

日付: 2026-10-11。状態: 採用。

ターン進行、AI判断、学習、日記、対戦セーブはローカルで動作する。外部サービスの存続や接続状態が保存・ロード・対戦の必須条件にならないようにする。

Git、パッケージ取得、Unityの制作サービスは開発工程の依存として扱う。製品は同梱したビルド情報を読み、GitやネットワークからVersionを取得しない。追加機能は既存Unityと標準ライブラリで実装し、新たな外部バイナリを要求しない。

Unityやパッケージの初回導入・ライセンス手続きが不要という意味ではない。Editor、解決済みパッケージ、アセット、ライセンス記録、製品を運用側で保管する。Dependency_Policy.mdを参照する。
