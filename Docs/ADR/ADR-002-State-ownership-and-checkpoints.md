# ADR-002: 状態の正本とチェックポイント

2026-10-11 / 採用。

実行中の正本はFactionState、Status、GameContext、Map/Vision。UI、AI観測、Saveはコピー。Scene/Transform依存を一度に撤去せず、実行・保存のアダプター境界を明確化する。

正式な保存は安定したプレイヤー操作フェーズに限定する。敵AI iteratorを保存・再開したかのように扱わない。PlayerStart再開では開始処理を重複実行せず、AP/残時間/状態効果/同一ターン中の使用フラグを復元する。

AI seedと性格は構築前に保存値を渡し、現在の通算Profileで過去の対戦設定を置き換えない。旧形式の実seedは失われているため、再現可能と偽らない。エンジン非依存の完全Replay/マルチプレイヤーCommandログは別の変更として設計する。
