# ADR-003: 表示名と永続IDを分離する

日付: 2026-10-11。状態: 採用。

駒・建物・イベント・報酬をセーブとAI記録から参照するため、表示名やUnityのInstanceIDでは識別しない。制作時に発行した定義ID、個体のReflectionLifeId、イベント・遭遇・報酬の固定IDを維持する。スキルの明示した整数IDと、旧保存値を維持するStableSaveKeysを使用する。

名称・分類・表示Prefabを変更しても参照が続く。引退したIDと旧キーは再利用しない。独立した駒の複製には新IDを発行する。旧兵種上書きには従来の兵種キーを残し、空definitionIdを許可する。

ビルド前に登録と参照を検証する。全アセットを名前からID化する移行やenum並べ替えは行わない。変更時はStable_ID_Policy.mdと旧セーブfixtureを更新する。
