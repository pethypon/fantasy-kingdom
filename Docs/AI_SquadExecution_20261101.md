# 工兵撤去・通常建築への復帰と部隊作戦の実行（2026-11-01）

工兵を生産・新規作成・AI補充から撤去し、鉱山を通常の領地内建築と生産へ戻した。部隊作戦には、既知地形での経路選択、複数ターンの進軍、中断・再開、補充の所有管理、前線への支援追従を接続した。

**部隊の実行機能は確認できたが、通常対戦で決着へ進むAIの完成は確認できていない。最終4試合は全て80～100ラウンドで未決着。王・主クリスタルへの攻撃は0件だった。** 制御された戦術試験の成功を、自律的な国家攻略の成功として扱わない。

## 変更したルールと維持した仕様

- 工兵の本番データ、カタログ登録、専用登録メニューを削除。召喚一覧、開発スタジオと旧工房の職種選択から外した。
- 旧セーブの数値を別職種へ読み違えないため、`Kind.Engineer` の数値は予約値として残す。旧工兵エントリーはロード時に生成しない。別職種への無断置換や返金はしない。工兵が過去に建てた建物は維持する。
- 古いイベント参照に必要な専用建築メソッドは、AP・資源を使わず失敗する互換入口に縮小した。旧設定で専用建築や2倍費用が復活することもない。
- 鉱山の自領土内での新規建築禁止と、鉱石系生産の「領土外だけ稼働」制約を撤去。通常の建築メニュー、通常の費用とAP、既存の生産レシピを使う。
- AIの建築費・生産予測も通常ルールへ統一。既存鉱山は領地変化によって生産停止しない。表示も「採掘：稼働」に変更。
- 生産量・建築費の表そのものは変更していない。通常兵の固定能力1.75倍、固定維持費5倍、ユニットの成長／XP廃止、兵舎XP廃止、正式AP、バリア、Fog、戦闘・地形ルールは維持した。

本陣座標・敵ユニットの現在座標を視界外から取得する経路は追加していない。敵目標の追従は正式観測中だけ行い、見失ったら既存の記憶を使う。自軍所有の駒・建物と正式な視界・探索済み地形を使う。

全試合で記録上のError・Exception・Assertionは0、作戦メンバーの重複サンプルは0。seed271828では施設等への `ObjectiveAttacks` が141 / 270件あったが、これは王・主クリスタルへの攻撃ではない。`VictoryObjectiveAttacks` は全試合0。敵主クリスタルを観測した選択ラウンドも0だったため、本陣を見つけた上で攻撃を選べるかは、この自然対戦では検証できていない。

正式実行器が占有マスへの移動を止めた失敗は3件（seed271828 Player 46・99ラウンド、seed141421/脅威度35 Enemy 67ラウンド）。失敗理由は全て `move_destination_occupied`。Fog下の占有と候補生成後の変化の切り分けは未完。成功として数えず、CSVへ残す。
