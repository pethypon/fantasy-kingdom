# クリスタルHP変更（2026-11-03）

- メインクリスタルの基本HP：5000 → **3000**。プレイヤー／敵のプレハブもUnityのPrefab APIで更新。
- サブクリスタルの標準HP：5000 → **1000**。登録済みの建物テンプレートの2000も1000へ統一。
- メインのHPルールをv2に更新。旧5000版／15000版のセーブは残りHPの割合と獲得済みの最大HP加算を保って移行し、ロードのたびに減算しません。撃破済みは復活させません。
- サブは既存の定義ベースの保存復元を使用。定義基準を持たない古いセーブも現在のHP設定へ割合を保って移行し、ATK・DEFを変更しません。
- 反撃、領土、費用、配置条件、勝敗条件、既存のHP増加報酬は維持します。将来のカスタム建物設定は引き続き編集可能です。

## 検証

Unity 6000.3.8f1で実行。新規HP契約13項目とPlay Mode7項目が合格。既存CoreLogic59項目も失敗0、既存のクリスタル統合契約45項目が合格しました。Runtime／Editor／Releaseの静的コンパイルも成功。

SampleSceneで実際に「はじめから」を実行し、20フレーム以上進行した状態で両陣営のメインが3000/3000であること、実際のBuildSystemで生成したサブが1000/1000であることを確認。登録済み建物データと両プレハブの値も確認しました。サブ建物生成は条件を用意した隔離フィクスチャによる確認で、自然な対戦のバランス評価ではありません。

既存セーブ互換性はHP割合、死亡状態、HP加算、繰り返しロードを実行して確認しました。長期対戦による決着時間への影響は今回未検証です。
