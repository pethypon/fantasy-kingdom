# 通常攻撃：自軍ターンに最大2回

各駒の通常攻撃は自軍ターンごとに最大2回。プレイヤーと敵AIで共通です。攻撃スキル・自動反撃・反射は別枠、召喚直後の攻撃禁止と、召喚上限1体は既存どおりです。攻撃には従来どおりAPと疲労を適用します。

開発スタジオ → 全設定 → 共通戦闘・召喚・クリスタルで変更できます。正式データ、データ新規作成時の初期値、データがない時の標準値をすべて2へ合わせました。セーブの使用済み攻撃回数はリセットせず引き継ぎます。
