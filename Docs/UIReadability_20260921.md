# UIの読みやすさ・ステータス統合 (2026-09-21)

## 表示と操作
- ホバー時の情報を下部ステータス欄へ統合。未選択時は「プレビュー / クリックで選択」、クリック後は選択対象を固定する。
- 攻撃・スキル・取消を一度だけ消費する入力として保持し、キーボード入力の更新による消失を防止。UI上の左クリックはマップへ渡さない。
- 敵が射程にいなくても攻撃モードを維持し、警告を表示。取消で元の選択と移動範囲を復元する。
- 施設効果は中央、強化と費用は右中央、破壊は右下、取消は右上へ分離。敵施設の強化操作も非表示。
- 資源・行動ボタン・建築/召喚一覧・操作ヒント・メニューの文字と余白を拡大。AP表示の初期化時のサイズ上書きも修正。
- 警告メッセージを右上へ移動し、下部操作欄と分離。横幅がアンカーによって二重に拡大していた問題も修正。
- 行動ログは幅320にして16:10でも中央パネルとの間隔を確保。

## 確認
- Unity 6000.3.8f1の実プロジェクトで再生。1920×1080と1280×800（最大化したGameビューも使用）を確認。
- 実マウス操作でユニット選択、攻撃モード、取消、ホバープレビューを確認。畑を建築・選択し、強化費用と破壊ボタンが重ならないことを確認。
- 建築一覧、召喚一覧、ゲームメニューの開閉と文字の表示を確認。
- 隔離検証プロジェクトで既存回帰テストと StatusUIRegressionTests 9項目が成功。
- Windows64の非Developmentビルドが成功（errors=0, warnings=0）。

Tests~/StatusUIRegressionTests.cs を既存の隔離検証プロジェクトの Assets/Editor に配置して、Tests~/SceneSmoke.cs と一緒に実行する。実プロジェクトのセーブを変更せず確認するため、検証用プロジェクトを使用する。
