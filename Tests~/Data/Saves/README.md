# 保存互換テスト

v0〜v6 は旧コードの形式を表す固定の合成データです。実際に公開済みの版やユーザーの保存ファイルから取得したものではありません。

テストでは元ファイルを更新しません。新しい移行を追加しても、既存ファイルを置換してテスト失敗を隠さないでください。公開時には実際の正常な保存スナップショットを別ファイルとして追加します。

v0 は Version を省略します。v0〜2 のクリスタル強化、撃破済みの維持、旧 MaxHP の補完、国ごとの生産位相、AI 履歴を捏造しないことを検査します。

SaveCompatibilityTests.RunAll() は OS の一時ディレクトリ内だけで読み書きします。正式なユーザー保存先にはアクセスしません。
