# Fantasy Kingdom 制作入口

Unityの **Fantasy Kingdom → 開発スタジオ（日本語）** で、駒・建物・陣営・資源・AP・第三陣営を設定します。再生停止中に編集し、「すべて保存」を押してください。**プロジェクト案内** から用途別のフォルダへ移動できます。

## ユニット作成

1. 「＋ 新しい駒」または「選択した設定を複製」を押す。
2. 表示名・分類・基礎役割・HP・攻撃・防御・成長・召喚費・維持費を設定する。
3. 行動タイプと、移動・通常攻撃・視界の8×8マスをクリック／ドラッグで設定する。
4. モデルを指定して専用Prefabを生成する。モデルなしでも基本形で作成できる。
5. ゲームへの登録を確認して保存する。

同じ基礎役割の駒を複数追加できます。それぞれの保存用ID、能力、Prefab、マス配置を持ちます。複製は別IDを発行します。表示名を変更しても保存用IDを変えないでください。「ユニット工房」のメニューも現在のスタジオを開きます。旧工房APIは既存兵種上書きの互換機能として残しています。

## 建物・ルール・第三陣営

「建物づくり」で建築費、AP、基本動作、レベル別能力、生産・投入材料・維持費・強化費を設定します。「既存の建物データを取り込む」は編集用の複製を追加し、登録するまで建築メニューへ追加しません。

「陣営・ゲームルール」で初期資源、AP、時間、地形、名前・色を設定します。初期値は新規ゲームへ、保存済みの状態はロードで復元します。共通ルールの設定変更は既存セーブにも適用される項目があるため、変更時はロード検証を行ってください。

「第三陣営のイベント」で襲撃の駒、発生条件、待機ターン、費用を設定します。ターン順は **プレイヤー → 敵軍 → 第三陣営 → 強敵** です。

## フォルダの役割

| 場所 | 内容 |
| --- | --- |
| `_FantasyKingdom/GameContent/Units` | スタジオで作成した駒・行動マス・専用Prefab |
| `_FantasyKingdom/GameContent/Buildings` | 建物と既存建物の編集用複製 |
| `_FantasyKingdom/Units` | 旧工房で作成した互換用ユニット |
| `Data` | 既存の能力値・設定 |
| `Prefabs` | 既存の駒・建物・ゲームシステム |
| `Resources/GameContent` | 有効な駒・建物の登録とルール |
| `Resources/AI` | AI・学習・作戦・第三陣営・診断の設定 |
| `Resources/Terrain` | 地形・霧・地形バリエーション |
| `Resources/UI` | UIテーマ |
| `Scenes` | シーン |
| `Script` | ゲーム本体コード |
| `Editor` | Unity内の制作・検証・ビルド機能 |
| `Gentleland` / `Honeti` / `TextMesh Pro` | 外部アセット。更新との互換性のため元の配置を維持 |

Resources読込名、公開した保存用ID、.metaのGUIDは参照の一部です。一括移動・変更をせず、変更する場合は読み込み箇所と旧セーブを確認します。

## 保存・検証・ビルド

**Fantasy Kingdom → 長期運用 → 全コンテンツと保存用IDを検証** で、登録中の駒・建物・イベント・遭遇・スキル・マス設定を検査します。同じ検査はビルド前にも実行します。未登録の編集用データや、旧兵種の空IDは許可します。

製品の横にFKBuildInfo.jsonを出力し、Version・Commit・UnityVersion・SaveSchemaなどを記録します。同梱用の情報アセットはビルド後に復元します。中断したビルドの復元メニューも長期運用メニューにあります。

詳しい操作は `Docs/DevelopmentStudio_StrategicGovernor_20261004.md`、ID方針は `Docs/Stable_ID_Policy.md`、ビルドは `Docs/Build_Manual.md`、更新検証は `Docs/Upgrade_Checklist.md` を参照してください。Tests~の検証は制作プロジェクトの隔離コピーで行います。
