# 盤面の効果音

移動、近接攻撃、射撃、魔法、被弾、回復、シールド、召喚、建築、補助スキル、勝利、敗北、UIクリックの13種類です。外部音源・素材集・生成サービスは使用せず、このリポジトリのPythonスクリプトで波形から制作しています。

すべてモノラル・22,050Hz・16bit PCMの短いWAVです。長さは0.10〜0.78秒、13個のファイル合計は225,482バイトです。低めの打撃・石・金属音と柔らかい魔法音を中心に、高い連続音を抑えています。前後のフェードとピーク66%への正規化で端のクリック音と音割れを防ぎます。

## Unityでの調整

`Assets/Resources/GameContent/BoardFeedback.asset` の「効果音」で、有効・無効、全体音量、同時再生上限、同じ種類の最小再生間隔、各音の音量とクリップを調整します。音量の初期値は全体35%です。新しいマテリアルやAudioListenerの追加は不要です。

`BoardSoundEffects.Play(BoardFeedbackKind kind, BoardFeedbackSettings settings)` が再生APIです。呼び出し元がFogによる可視性とセーブ復元中の抑制を判定します。`StopAll()` は音を即時停止し、プールを再利用可能な状態で保持します。

- 盤面全体で最大8個のAudioSourceを必要な数だけ作り、再利用します。設定の上限がさらに小さければその範囲だけ再生します。
- 同種・同フレームの音は1回までです。最小間隔も種類ごとに適用するため、範囲攻撃や多重クリックで音が重なり続けません。
- 全ボイス使用中の通常音は破棄します。勝敗音は通常音から最古のボイスを置き換えます。
- 音声は2D再生です。新しいAudioListenerや常駐シーンオブジェクトは作りません。シーンを閉じるとプールも破棄されます。
- `BoardSoundEffectsDriver` のフレーム処理は再生中のみです。最後の音が終わるとコンポーネントを無効にします。
- `VoiceCount` は作成済みのボイス数、`PlayingCount` は実再生中の数、`AcceptedPlayCount` は受理した再生要求の累計です。音声デバイスのない自動検証でも要求受付を確認できます。

## 再生成

プロジェクトのルートで、Python 3.10以降を使用します。追加ライブラリは不要です。

```powershell
python Tools/Audio/GenerateBoardSounds.py
python Tools/Audio/GenerateBoardSounds.py --verify
```

スクリプトは専用の固定シードを持つ `random.Random` を使用します。Unityの乱数やゲームデータには触れません。同じスクリプト・Python環境なら同じWAVを再現します。`--verify` は既存ファイルとの一致、サンプルレート、長さ、無音で終わること、クリップしていないことをファイルを変更せずに検証します。

既存の `.meta` がある場合は保持するため、クリップの参照GUIDは再生成後も変わりません。音の性格を変えるときは `synthesize` の該当種類を変更します。
