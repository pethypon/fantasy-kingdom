# 16職種の金属チェス駒

ゲーム中にポリゴンやマテリアルを組み立てず、Editorで事前に焼き込みます。既存10職種の召喚用Prefabが球体のままだったため、それらと新6職種に職種別モデルを導入します。初期Knight・Archer・Scoutの完成モデルやKing・StrangeKing等の別Prefabは変更しません。

台座は共通の真鍮と濃い金属色です。各職種は1 Mesh、1 MeshRenderer、1 SubMesh。全16職種で `ChessMetal.mat` と小さな `ChessPalette.png` を共有します。独自のUpdate、ParticleSystem、透明描画、追加Colliderはありません。元のStatus、SphereCollider、Prefab GUID、Stats、能力、移動・攻撃・視界マスクを維持します。

Unityのメニュー:

- **Fantasy Kingdom → 開発スタジオ → 駒の見た目 → 16職種の金属チェス駒を導入（未加工モデルのみ）**
- **Fantasy Kingdom → 開発スタジオ → 駒の見た目 → 生成モデルを検証**
- **Fantasy Kingdom → 開発スタジオ → 駒の見た目 → 16職種の見本画像を作成**

新6職種の導入先は `GameContent/R1Production/Units/<職種>/Visual.prefab`、既存10職種は両陣営の召喚で共用する `Assets/Prefabs/Units/Player/<職種>.prefab`。明示的に導入した時だけ、元の球体のままで階層・Collider・マテリアル等を変更していないモデルを移行します。別のPrefabや独自Meshへの差し替え、独自Material、追加の子やComponentがあれば保持します。再導入時は焼き込み済みMesh・Material・Prefabを生成し直しません。

見た目を編集する時は、各職種の `Visual.prefab` のMeshFilterまたはMeshRendererでモデルやマテリアルを差し替えられます。元のStatusと選択用Colliderは維持してください。

`Review/R1ChessUnits.png` は4列×4段。左から右、上から下へ、ナイト・アーチャー・魔法使い・アサシン、斥候・プリースト・ガーディアン・クロスボウ、マジックスナイパー・ボンバー・白魔導士・聖騎士、侍・忍者・狂戦士・航海士です。照明とカメラを分離した見本用シーンで撮影します。実ゲームのカメラやシーンは変更しません。

隔離した検証プロジェクトで `R1UnitVisualTests.InstallAndRun` を呼ぶと、導入前後のStats・Status・Collider・Prefab GUID、ポリゴン数、共有参照、再導入時の非破壊性を確認できます。
