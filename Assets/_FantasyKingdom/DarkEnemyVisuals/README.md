# 敵の異形モデル・強敵モデル

ユーザー指定の4 OBJを実際の駒へ使用しています。元ファイルを読み取り専用として扱い、別連結の大きな台座だけを低負荷な共通台座に交換しました。異形の本体、脚、顎、角、触手、鰭は元モデルから残しています。味方の16職種モデルやゲームの能力データは変更しません。

## 制作と導入

Unityメニュー `Fantasy Kingdom → 開発スタジオ → 駒の見た目 → 敵の異形17種と強敵4種を導入`。

APIは `DarkEnemyVisualInstaller.Install()`、`ValidateAssets()`、`RenderPreview()`、`InstallAndReview()`。

生成済みMesh・Prefab・Materialがあるときは再生成しません。Unityで編集した見た目を再導入で上書きしないためです。意図して再制作する場合は対象の生成Mesh/Prefabだけを別名で保管してから再導入してください。元OBJを変更してもゲーム中の自動インポートや自動再生成はしません。

Prefabは表示専用で、MeshFilterとMeshRenderer各1つ、追加Collider/Status/MonoBehaviourは0です。陣営や能力は既存の本体に残します。アニメーションは実行側の表示ルートを動かす方式で、駒の座標・当たり判定を動かしません。

## 元モデルと負荷

| 元ファイル | 元の三角形 | 軽量化後の本体 |
| --- | ---: | ---: |
| 鯉　異形 2完成.obj | 126,949 | 2,072 |
| 羊の異形　下級完成 .obj | 32,351 | 1,799 |
| 蟹の異形　下級 完成.obj | 20,033 | 1,798 |
| 犬の異形　下級.obj | 15,258 | 1,799 |

完成した通常駒は3,400三角形以下、強敵は4,600三角形以下。各1 Mesh・1 Rendererで共有マテリアルを使います。ループするParticleSystem、Animator、リアルタイムLight、追加の影を持たせていません。元OBJの大きなテクスチャや存在しないMTL絶対パスにも依存しません。

元ファイル名・SHA256・元/軽量化後三角形数を `Sources/*.json` に記録しています。ゲームのビルドが参照するのは生成Mesh/Prefabであり、Sources JSONや外部OBJを実行時に解析しません。

再現用オフライン処理は `Tools/Art/BakeEnemySources.py`。Blender 4.4のバックグラウンド処理で、元モデルの連結成分から台座を識別し、Decimate後にUnity用の座標系と法線へ変換します。長い鯉は20度だけ頭を上げ、横の輪郭が見える姿勢で一マスへ正規化します。台座へ繋がる尾、装備を握る爪の腕、盾や爆嚢の支持部を加え、装備だけが空中に離れない構造にしています。装備は本体の輪郭を隠さない大きさへ縮小しています。原本を書き換えません。

2026-10-18の造形調整では、職種を識別しにくかった犬・鯉の装備の高さを、本体に埋もれない比率へ引き上げています。鯉のMeshだけを生成段階で縦1.43倍、奥行1.10倍とし、元の顔・鰭・尾を残したまま見下ろし視点の薄さを軽減しました。通常の剣と鎌には厚みと中央稜線、盾には閉じた裏面と側面を持たせています。外套・旗・翼膜も折れ目と裏面を持つ閉じた形で、横から見ても一枚板になりません。装備の支持位置は生成時の縮小率から計算し、手だけが以前の位置へ取り残されることを防ぎます。変更はEditorのMesh生成だけで、ゲーム中に形を計算し直す処理や追加Rendererはありません。

## 材質

MeshのUVは旧R1との互換を保ちますが、本番の石目は既存マテリアルのオブジェクト座標によるトライプラナー投影を使います。武器・角・盾・眼の造形で役割を識別します。既存の `異形　キャラクター　黒.mat` と `敵　キャラクター　赤.mat` をそのまま共有参照します。新しいMaterialやテクスチャは作成しません。元のMaterialを編集せず、モデルごとの複製も行いません。

見本画像は `Review/EnemyAberrations.png` と `Review/BossAberrations.png`。並びは同名のtxtに左上から行順で記載します。見本の補助光は撮影シーンだけに存在し、本番に追加しません。

未公開の検証用Meshを更新するAPIは `DarkEnemyVisualInstaller.RebuildForValidation()`。`UnityValidation`プロジェクトだけで動作し、21MeshのGUIDを維持して形だけを更新します。通常の制作プロジェクトでは生成済みモデルを自動上書きしません。
