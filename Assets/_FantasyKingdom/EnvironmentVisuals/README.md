# 開始時の環境と見た目

`Fantasy Kingdom > 開発スタジオ > 環境 > 開始時の環境と見た目を導入（未設定値のみ）`
または Editor の `TerrainEnvironmentProductionInstaller.Install()` を明示的に実行します。
初回は標準カタログの未設定値と空の見た目を補い、環境および開始時生成を有効にします。
自動起動フックやゲーム実行中のアセット変更はありません。

`EnvironmentProductionSettings.asset` に暫定値と導入履歴を保存します。
導入済み定義の調整値・有効無効と、導入済みカタログの生成設定は再実行で変更しません。
既に割り当てた独自プレハブも保持します。暫定値はゲームバランス確定値ではありません。

| 項目 | 初回の未設定値補完 |
|---|---|
| 森・草むら・煙の確認距離 | 1マス（斜めを含む） |
| 森の攻撃後露見 | 2ラウンド |
| 毒沼の侵入時・所有ターン開始時 | それぞれ最大HPの5% |
| 泥・道 | 移動AP +1 / -1（実移動APの下限は既存ルールの1） |
| 回復泉 | 所有ターン開始時に最大HPの5% |
| 洞窟 | 到着後の再利用待機2所有ターン |
| 焼却後と独立した煙 | 30ラウンド、所有ターン開始時に最大HPの10%、確認距離1 |
| 間欠泉 | R1の既定値で最大HPの25%。発見情報は既存ランタイムが管理 |
| 岩場 | 未導入の標準定義だけ通行・射撃可能に移行（被遠距離×0.75を利用可能）。奥の視界遮断は保持 |

森・草むらの3〜4マス連結、生成率、保護距離等はカタログの日本語生成設定で変更します。
開始時生成は煙を含みません。手動配置と洞窟接続は既存の環境設定画面で編集できます。

## 描画

10種類の `Prefabs` と `Meshes`、1つの `EnvironmentPalette.mat` をEditorで生成します。
各プレハブは1メッシュ・1描画・1共有マテリアルです。実行時には共有アセットを通常の
Instantiateで使い、実行時メッシュやマテリアルの複製、更新スクリプト、物理Collider、
Status、影の投影を追加しません。見えるかどうかは既存のRefreshVisibilityに従います。

接地はマス位置からY=-0.48。1マス内に収まり、森は小さな外周の針葉樹、草むらと煙は
低い外周の塊、岩場は低い外周の岩で中央を空けています。歩ける駒やHP表示を読みやすくします。

`TerrainEnvironmentProductionInstaller.ValidateAssets()` は10種の存在、共有描画参照、
三角形数（各900以下）、1マス・高さ制限、Collider/Status/MonoBehaviourなしを確認します。
`RenderPreview()` はユーザーのシーンを開かず、Review/EnvironmentVisuals.png に5列×2行の
確認画像を生成します。順番は上段が森・草むら・岩場・毒沼・泥、下段が道・回復泉・間欠泉・洞窟・煙です。

根拠: Docs/Environment_R1_20261017.md と TerrainEnvironmentDefinition.ConfigurationError。
未指定だった露見・ダメージ・AP・回復・待機値は今回の開始時導入用の暫定値です。
